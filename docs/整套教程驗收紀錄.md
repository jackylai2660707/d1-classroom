# D1 機器狗實驗室 2.0 驗收紀錄

版本 2.0.0，2026-10-21。環境：Windows x64、Microsoft Edge、Node.js 22、Electron 38、Python 3；本次未連接實體機器狗或相機。

## 教程與列印資料

- 21 頁：課程首頁、16 課、學生開始、教師帶課、設備部署、版本與來源。
- 1440 / 390 / 320 像素寬度及每課 4 個章節，共 207 次版面 / 章節檢查；頁面無水平溢出，必要表格使用內部橫向捲動。
- 所有本地連結與圖片可用；以 file URL 開啟，閱讀與記錄互動沒有外部網路請求。
- 已驗證起步專案下載、本課記錄匯出 / 重開 / 匯入、錯課檔拒絕且不改資料、文字安全顯示、圖片放大與投影閱讀。
- 16 頁工作紙、18 頁教師手冊、5 頁操作 / 試教 / 色卡；39 頁均完成 Poppler 渲染及頁面檢視，文字可擷取，無舊版 ID 連線指令。
- 舊 Word / PPT / PDF 已歸檔，正式套件不混用舊操作。

## Windows 成品與程式

- 16 課程式全部通過：第 1–14、16 課使用練習模式；第 15 課使用合成即時影像驗證連續畫面確認後轉向，以及沒有左轉卡時超時、跳過轉向。
- 模型 ZIP 匯入與示例圖分類通過。示例圖的分數只驗證推論流程，不能代表實景準確率。
- 成品「本課教程」開啟所選課次的真實本地檔案；無效課次被拒絕。
- 真實 UDP / HTTP 假 SDK 流程通過：MAC 掃描、連線、占用拒絕、假動作、橋接中斷取消，以及新使用者資料重新掃描連線。
- 核心 JavaScript 7 項通過；Python 23 項中 22 項通過、1 項 Linux shell 檢查在 Windows 按設計跳過。橋接與初始化程式本版未改動運動行為。

## 發佈完整性

發佈腳本核對原廠 SDK SHA-256、兩種 Linux 架構二進位檔與原廠授權；初始化 ZIP 內含完整原包。完整套件與原始碼 ZIP 均做 CRC 檢查，檔案清單.csv 提供每個交付檔案的大小與 SHA-256，發佈後另以完整性稽核核對。

新版原始碼只包含目前的網頁、PDF 與應用建置入口，附作者 Python 依賴版本與驗收紀錄；不依賴 Word、PowerPoint、LibreOffice 或 artifact-tool。

原始碼 ZIP 已解壓到獨立目錄，成功重新生成 16 課、32 份起步檔與三份 PDF。完整套件 ZIP 也已另行解壓到新位置，通過 EXE 啟動、練習運行、對應課件按鈕和 16 課地圖導覽，沒有依賴原工作區的絕對路徑。

尚未驗證實體狗的 SDK / 韌體相容、開機自啟、真實動作、停止延遲與距離、機身 RTSP，以及整班多組負載。第一次上課前按設備部署指南與列印驗收表逐台完成；未通過前使用練習模式。
