## 動作

| Python | 原廠高層介面 | 說明 |
|---|---|---|
| dog.greet() / dog.shake_hand() | shakeHand | 先站立且靜止，再打招呼／握手 |
| dog.passive() | passive | 阻尼趴下，不替代硬體急停 |
| dog.side_left(seconds=0.5, speed=0.1) | move | 向左側移；右側為 side_right |
| dog.move(vx=0.1, vy=0, yaw_rate=0, seconds=0.5) | move | 組合平移與轉向；平移合速度上限 0.2 m/s，單次上限 3 秒 |
| dog.attitude(pitch=0.05, seconds=0.5) | attitudeControl | 參數是角速度／高度速度，並非角度；roll/pitch/yaw 上限 ±0.1 rad/s，height 上限 ±0.02 m/s，單次最多 1 秒 |
| dog.jump() | jump | 高風險原地跳 |
| dog.front_jump() | frontJump | 高風險向前跳 |
| dog.two_leg_stand(seconds=1) | twoLegStand(0, 0) | 高風險原地雙腿站立，最多 2 秒；此工具不開放雙腿行走 |
| dog.cancel_two_leg_stand() | cancelTwoLegStand | 退出雙腿站立；期限或停止也會嘗試退出 |
| dog.backflip() | backflip | 危險後空翻，預設隱藏 |

保留原有 stand、lie、stop、forward、back、turn_left、turn_right、wait、battery。官方高層介面沒有獨立坐姿指令，不將 lie 假稱為坐姿。未加入逐電機控制、LowLevel 或其他帶輪型號專用介面。

姿態調整結束會發送零姿態速度；接下來行走前需重新 stand。SDK 回傳非零錯誤碼會顯示並拒絕宣稱動作完成。已回報阻尼／趴下的模式不再發送無效的 move(0,0,0)。所有停止仍需要現場目視確認。

## 高風險功能

- 實機預設不允許跳躍、雙腿站立或後空翻。每個程序要明確勾選「允許本次程序執行高風險動作」，執行確認視窗會顯示失衡、碰撞、夾傷及設備損壞風險。
- 後空翻需展開危險區、勾選顯示指令，再另外勾選「允許本次程序執行後空翻」。只顯示積木不等於取得執行允許。
- 允許只存當次程序記憶體，結束／取消後重設，不隨作品匯入，不存到機身設定。橋接亦驗證這兩項旗標，手打 Python 不會繞過。
- 跳躍／後空翻沒有原廠高層取消介面；停止時會明確回報未確認，不假裝零速度能中止已開始的特技。動作等待時間是工具的保守等待值，不是實體完成感測。
- 頻繁特技會增加部件磨損。只在符合原廠要求的場地、有熟悉硬體停止的人員現場監看時逐項驗收。未實機驗收前可用練習模式檢查程式，但不能把練習模式當成物理模擬。

## 感測資料

讀取仍受控制權與每次程序 60 秒上限約束；短時間重複讀同項目會使用快取，避免高速輪詢 SDK。練習模式會清楚標記為示意資料。

| Python | 回傳 |
|---|---|
| dog.mode() | 原廠控制模式碼 |
| dog.quaternion() | [w, x, y, z] |
| dog.rpy() | [roll, pitch, yaw]，rad |
| dog.acceleration() / dog.gyro() | 三軸加速度 m/s²／角速度 rad/s |
| dog.position() | 相對開機原點位置，m |
| dog.world_velocity() / dog.body_velocity() | 原點／機體座標系速度，m/s |
| dog.joints_position() | abad、hip、knee 三組角度，rad |
| dog.joints_velocity() | 三組角速度，rad/s |
| dog.joints_torque() | 三組扭矩，N·m |

關節資料為字典，每組依 FR、FL、RR、RL 排列。不要把原點位置當作已校準的室內定位。

## 持續辨識

原 vision.wait_for 是一次事件，仍保留原有消耗／重新展示機制。新增：

- vision.label()：讀目前穩定類別；連續三張新畫面分數至少 0.8 才穩定，可持續讀取同一張卡，沒有穩定類別回 None。
- vision.is_label("a")：目前穩定類別是否為 a。
- vision.score("a")：最新一張辨識結果中 a 的分數（0–1），不是三張確認事件。

這些方法必須有即時相機與新推論結果；靜態測試圖片及過期畫面不允許觸發。label/is_label 可用 min_score 指定 0.8–1 的最新分數門檻；基本三張確認仍採 0.8。

先只列印：

```python
for count in range(10):
    print(vision.label())
    dog.wait(seconds=0.5)
```
