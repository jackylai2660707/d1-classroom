## 驗證與參考

- 核心測試：根目錄執行 powershell -NoProfile -File scripts/test.ps1。
- 離線教程與成品入口：d1-classroom/tests/courseware-smoke.cjs --packaged。
- 成品模型與練習：tests/packaged-smoke.cjs。
- 假 SDK 完整流程：tests/app-smoke.cjs --packaged。
- 詳細命令：[測試指南](測試指南.md)。驗證證據：d1-classroom/build/qa/courseware/（本機執行後產生，Git 不追蹤）。
- 網路設計：[機器狗掃描連線設計](機器狗掃描連線設計.md)。技術細節：[部署文件](../d1-classroom/技術部署與實機驗收.md)。
- 原廠與研究資料：references/。歷史教材：references/歷史教材/1.0-20261020/；舊建置：references/歷史建置/1.0-20261021/。完整參考資料由私人 Release 下載。
- 先前實作與整理紀錄：實作驗收紀錄.md、整理與測試紀錄.md、清理紀錄.md、cleanup-manifest.json；這些是歷史紀錄，不代表新版本自動通過。
- 本地完整索引：執行 python scripts/update_index.py 產生 docs/檔案索引.csv，Git 不追蹤這份電腦特定清單。

正式交付不含 Word / PPT 或舊版 ID 教材；歷史資料保留在 references，不混入新套件。
