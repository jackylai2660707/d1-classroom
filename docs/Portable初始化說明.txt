機器狗初始化 Portable（Windows x64）
==================================

1. 把整個 ZIP「全部解壓縮」到可寫入的資料夾，例如桌面。
2. 先讓狗趴穩、保持靜止，停止程式並斷開其他控制端。
3. 電腦連上與狗相同的 Wi-Fi，或直接連狗的 AP；不需網際網路。
4. 雙擊「初始化新機器狗.cmd」。
5. 輸入狗當前 IP，按 Enter。預設使用 firefly 帳號與原廠共同密碼。
6. 等待「初始化成功」和完整 Wi-Fi MAC，再去學生工坊掃描並核對 MAC。

不必安裝 Python、PuTTY、OpenSSH、Node.js 或 pip，不改 PATH，不要求管理員。
包內已附固定版本 x64 Python、VC runtime DLL、Plink、完整原廠 SDK 與授權。
只使用 Windows 10/11 64 位元系統內建的 CMD、PowerShell 與檔案權限工具。
不支援 32 位元 Windows；Windows 11 ARM 可由系統相容執行 x64 工具。
如果公司策略封鎖 PowerShell／未知程式，需由 IT 放行，portable 不會繞過政策。

「檢查工具.cmd」只測內附執行環境、SSH 與檔案雜湊，不連機器狗。
每次啟動會先核對 PORTABLE-MANIFEST.json 的檔案 SHA-256，損壞時直接停止。
整包可複製到另一台 Windows 電腦，不要只複製 CMD 或只複製 Python.exe。

安裝流程與限制
==============

* 只自動處理已驗證 XG 0.5.1-xg、Ubuntu 22.04 ARM64／CPython 3.10 的機身配置。
  未知型號、腳本或韌體會停止，不修改或升級作業系統。
* 首次 SSH 指紋採信任首次使用，會列出指紋與讀取的 MAC；後續同 MAC 金鑰變更拒絕。
* 安裝會備份、設定機內回環地址，必要時單獨重啟原廠運控，並啟動 SDK／橋接。
  SDK 可能接管手柄／App；請現場備妥原廠硬體停止方式。
* 不執行站立、趴下、握手、跳躍、後空翻或其他動作測試，不改 Wi-Fi／DHCP／防火牆。
* 失敗時嘗試還原；顯示逾時後讓狗保持開機至少三分鐘，不要反覆重跑或拔電。
* 新狗預設不設開機自啟。成功是軟體／SDK 就緒，不是動作或物理停止驗收。

工具的暫存檔在本包 local/，記錄、MAC 與主機指紋在 field-results/。
密碼不放在命令列或記錄；登入期間使用限制權限的短暫檔案，正常結束會刪除。
強制終止工具可能留下 local/robot-init/ssh-*.tmp，請檢查並刪除這些暫存密碼檔。
搬動工具時不要把自己產生的記錄、暫存密碼或學生作品分享給別人。

本包是獨立的新工具，不會覆寫 GitHub 已發布的 v2.1.0 附件。
此工具尚未完成新狗的完整首次實機初始化驗收。
