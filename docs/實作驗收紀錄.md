# D1 學生工坊 1.1.1 實作與驗收紀錄

日期：2026-10-20。版本：1.1.1。

## 已交付的軟體

- Windows 學生端新增「掃描機器狗」與 MAC 設備列表；點選連線、顯示電量、占用拒絕，沒有 ID 輸入框或課室設定。
- 使用 DHCP 與 UDP 廣播發現，直接取回覆來源 IP；狗端僅回覆所選 Wi-Fi 網段，避免多網卡重複回覆。
- 不生成 UID、不配對、不保存學生端憑證；本次控制憑證僅存記憶體。保留動作限制、心跳、停止及逾時釋放。
- 同一份 install.sh／install.py 初始化每隻狗，自動選 Wi-Fi 網卡、讀 MAC、檢查 SDK、安裝與啟用開機服務、產生標籤檔；重複安裝保存已選設定及一份前版備份。
- 更新原始碼、部署說明、連線使用說明、打包及發佈流程，移除舊 provision.py、robots.json 與未使用的靜態服務範本。

## 尚需實機與課室驗收

- 在實體 D1 執行 install.sh，確認 CPython 3.10 原廠 SDK、機型、韌體與機內通訊配置相容，及開機自啟與 CPU 負載。
- 真實 Wi-Fi 廣播、防火牆、DHCP 換址／換路由器後的連線與 RTSP，及 10 台電腦／10 隻狗負載。
- 真實站立、低速短動作、停止延遲／距離、斷網／程式退出／SDK 故障的現場停止效果。
- 教師培訓、零基礎試讀與每課 45 分鐘試教。

初始化成功僅表示軟體檢查通過，不能替代上述現場證據。SDK 機內配置不匹配時腳本會失敗並提示處理，未宣稱所有出廠映像都能直接成功。
