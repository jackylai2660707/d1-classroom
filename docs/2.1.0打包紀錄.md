# 2.1.0 本機打包紀錄

日期：2026-10-31。使用者要求將目前功能一次打包，讓原「啟動學生工坊.cmd」直接開啟新版。版本由 2.0.0 升為 2.1.0；準備新的本機 Release 附件與清單，不修改已發佈的 v2.0.0 標籤／manifest，不自動推送或發布 GitHub。

## 內容

- 新高層動作、感測資料、持續辨識、高風險動作逐次允許與預設隱藏後空翻。
- 心跳鎖分離、HTTP 連線重用、站點 Wi-Fi／ap0 探索支援。
- 輸入 IP 初始化工具及完整 SDK／授權、安裝與還原程式，獨立目錄結構可離線使用；電腦需 Python、OpenSSH、PuTTY。
- 16 課教程與 32 份起步檔內容未改。教程版號改由 package.json 取得；三份 PDF 與下載保存的 v2.0.0 原成品逐位元組相同，保留既有 PDF 版面。

## 建置與驗證

固定使用本機 x64 Node 24.18.0／pnpm 11.0.9。首次 pnpm 執行觸發依賴自動檢查後，使用 verify-deps-before-run=false 執行既定 bundle/package；未修改 lockfile 或換成 ARM 成品。package.cjs 現在於複製前核對 Electron 與 FFmpeg 的 PE Machine=0x8664，拒絕非 x64。

已核對新 app.asar 的 package version 2.1.0，renderer.bundle.js、robot-api.js、python-worker.js、main.cjs、policy.cjs 與來源完全一致。最終 ZIP 必須在此 ASAR 完成後重建並進行 delivery-audit，避免包含舊包。

本輪軟體驗證包括核心測試（JS 9、Python 59 中 58 通過／1 Windows 跳過、Release 不可變 2）、打包 EXE fake SDK UI smoke、打包 16 課練習與模型／合成相機分類，以及 courseware-smoke --packaged（21 頁、207 個不同視窗／章節檢查、離線零網路請求、匯入／匯出、教程入口）。具體輸出保存在本機 build/qa/；最終附件與 SHA-256 見 releases/v2.1.0.json。

## 實機驗收限制

先前現場記錄包含單台機身 SDK 回環連通、掃描、部分基本動作由使用者回報，以及心跳短測；本次打包驗證不操作真狗。新動作（握手、側移、姿態、跳躍、雙腿與後空翻）、實體停止、AP 切換、開機、多機負載均不能據本次假 SDK 通過宣稱已驗收。新狗完整初始化腳本亦尚待首次實機驗證。學生預設維持練習模式，高風險功能預設未允許。
