## 公司電腦文件與工具

- docs/公司電腦實機測試.md：clone、Release、離線練習、網路與 SSH、一次初始化、開機自啟、單狗到多狗驗收、排錯及回復。
- docs/實機測試記錄範本.md：記錄 commit、版本、MAC、韌體、現象及證據，複製到 field-results/ 使用。
- scripts/fetch-release.ps1：下載私人 Release；先核對大小與 SHA-256，再解壓，既有成品保留，-Replace 先歸檔。
- scripts/preflight.ps1 / preflight.py：只讀檢查公司電腦、SDK 和成品，結果留在忽略的 field-results/。
- scripts/check_repository.py：提交前檢查 Git index，拒絕敏感檔名、常見憑證特徵、超大 blob 或非 LF shell。
- scripts/prepare-release.py：準備 Release 成品與版本雜湊清單。
