# D1 學生工坊 2.0：掃描與連線

1. 電腦與狗加入同一個可互通的課室網路，打開學生工坊。
2. 點「掃描機器狗」，對照狗身標籤的完整 Wi-Fi MAC，在同一列點「連線」。
3. 再核對畫面 MAC 與電量，保持練習模式；老師示意後才實機測試。
4. 結束後點停止，目視確認，再斷開並保存作品。

使用中的狗不能搶連。學校電腦重啟還原後重新掃描即可，不需匯入課室設定或首次配對。DHCP 可以適應不同局域網，前提是電腦與狗在同一個允許廣播、可互通的 IPv4 網段。

完整圖解見套件的「使用說明.html → 學生開始」。16 課已同步使用 MAC，工具中的「本課教程」開啟所選課程。

掃不到時請老師確認電源、橋接服務、Wi-Fi、隔離設定與防火牆。模型、程式和相機在 Windows 執行；不能在斷開後繼續學生程式。

每隻狗由技術人員執行同一份初始化腳本。SDK 已附，詳見「技術部署與實機驗收.md」。初始化成功後仍需現場完成動作與停止驗收。
